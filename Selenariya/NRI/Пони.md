# 🎲 🧠 КАК ИГРОК СОБИРАЕТ БРОСОК

👉 Всегда одно и то же правило:

**Игрок собирает пул из 3–5 кубов:**

|Что выбрать|Пример|Куб|
|---|---|---|
|Подход (как действует)|аккуратно, быстро, агрессивно|d6–d10|
|Гармония|дружба, честность и т.д.|d6–d10|
|Отличие (черта)|«смелый», «ленивый»|d8 или d4|
|+ бонусы|предметы, помощь|d6+|

👉 Потом:

- кидает ВСЕ кубы
- берёт **2 лучших = результат**
- 1 любой = **эффект**
- **эффект**

---

# 🎯 ЧТО ГОВОРИТ МАСТЕР (главное)

Когда игрок что-то делает — ты говоришь:

👉 **«Это преодоление / создание / атака»**

---

# ⚡ 1. ПРЕОДОЛЕТЬ (Overcome)

|Когда|Что делать|
|---|---|
|пройти, обойти, взломать, найти|кидают пул|

### 🎲 Игрок кидает:

- Подход
- Гармонию
- Отличие

### 🎯 Против:

|Сложность|Кубы мастера|
|---|---|
|легко|2d6|
|средне|2d8|
|сложно|2d10|

---

# 🧩 2. СОЗДАТЬ ЧЕРТУ (Create Advantage)

|Когда|Пример|
|---|---|
|хочет помочь себе|«я создаю дым»|
|хочет ослабить врага|«я отвлекаю»|

### 🎲 Игрок кидает:

то же самое (пул)

### ✅ Результат:

| Успех   | Что появляется |
| ------- | -------------- |
| обычный | d6             |
| хороший | d8             |
| сильный | d10            |
👉 Пример:

- «ослеплён d8»
- «скользкий пол d8»

---

# ⚔️ 3. АТАКА (Contest)

|Когда|Пример|
|---|---|
|драка|удар|
|спор|переубедить|
|магия|навредить|

### 🎲 Оба кидают:

- свои пулы

👉 Сравнение:

- у кого больше сумма — тот выиграл

👉 Победитель:

- наносит **стресс = эффект-куб**

---

# 💥 ЧТО КИДАТЬ ИГРОКУ (ГОТОВАЯ ШПАРГАЛКА)

|Игрок говорит|Ты говоришь|Он кидает|
|---|---|---|
|«Я ищу»|преодолеть|подход + гармония + отличие|
|«Я убеждаю»|атака (социальная)|то же|
|«Я крадусь»|преодолеть|то же|
|«Я дерусь»|атака|то же|
|«Я делаю ловушку»|создать|то же|
|«Я отвлекаю»|создать|то же|

# ⚠️ ЕСЛИ ВЫПАЛА 1

|Что происходит|
|---|
|мастер получает жетон|
|делает осложнение|

# 🧠 КОРОТКО ДЛЯ ИГРОКОВ (можно им сказать)

👉 «Выбираешь:

- как действуешь
- свою черту
- свою гармонию

Кидаешь всё → берёшь 2 куба → это результат»

---

# 🎯 КОРОТКО ДЛЯ ТЕБЯ (МАСТЕРА)

👉 Ты всегда решаешь только 2 вещи:

1. **Тип действия**

- преодолеть
- создать
- атака

2. **Сложность**

- 2d6 / 2d8 / 2d10



**Стела** -------------
Стэн белая трощяа


# 🎲 🧠 ГЛАВНАЯ ТАБЛИЦА (ЧТО КИДАТЬ ИГРОКУ)

| Что происходит      | Какие кубы ОБЯЗАТЕЛЬНО                |
| ------------------- | ------------------------------------- |
| Любое действие      | **1 Подход + 1 Гармония + 1 Отличие** |
| Есть предмет/помощь | + Актив (d6–d10)                      |
| Есть проблема       | + Осложнение (мешает)                 |
| Потратил очко       | + d6 или d8                           |

👉 **Минимум всегда: 3 куба**

---

# 🎯 ТАБЛИЦА ПОДХОДОВ (КАКОЙ КУБ БРАТЬ)

|Действие игрока|Подход|
|---|---|
|думает, анализирует|Умный|
|быстро действует|Быстрый|
|просто бьёт/давит|Прямолинейный|
|красиво, харизматично|Впечатляющий|
|аккуратно, осторожно|Осторожный|
|странно, креативно|Нестандартный|

👉 Берёшь **его куб (например d8)**

---

# 🌈 ТАБЛИЦА ГАРМОНИИ (ПОЧЕМУ)

|Ситуация|Куб|
|---|---|
|помогаешь|Доброта|
|защищаешь|Верность|
|говоришь правду|Честность|
|шутишь/разряжаешь|Смех|
|жертвуешь|Щедрость|
|колдуешь|Магия|

👉 Берёшь **1 куб**

---

# 🎭 ТАБЛИЦА ОТЛИЧИЙ

|Как используешь|Куб|
|---|---|
|помогает|d8|
|мешает|d4 + получаешь очко|

---

# ⚔️ ТАБЛИЦА ТИПОВ ДЕЙСТВИЙ

|Тип|Когда|Что кидать|
|---|---|---|
|Преодолеть|пройти, сделать|обычный пул|
|Создать|дать эффект|обычный пул|
|Ставка (бой)|атака/конфликт|обычный пул|

👉 ❗ ВАЖНО:  
**кубы НЕ меняются — всегда тот же пул**

**сложность (2d6–2d12) или кидаешь за врага**
